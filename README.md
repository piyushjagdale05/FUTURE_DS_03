# FUTURE_DS_03
📊 Marketing Funnel Analysis Project
🔍 Project Overview

This project analyzes a bank marketing campaign dataset to evaluate customer conversion performance.

The goal is to understand how customers move through the marketing funnel and identify high-performing customer segments using data analysis and visualization.

🎯 Objectives

🧹 Perform data cleaning and preprocessing

📐 Calculate key performance indicators (KPIs)

🔄 Build a marketing funnel

👔 Analyze conversion rate by job and month

📊 Create a multi-chart dashboard

💾 Automatically save dashboard output

📁 Dataset Information

📌 Dataset: Bank Marketing Dataset

👥 Records: 45,000+ customers

🎯 Target Variable: y

Target Variable Meaning:

✅ yes → Converted

❌ no → Not Converted

📈 Key KPIs

👥 Total Customers

🟢 Converted Customers

📊 Overall Conversion Rate

🖥 Dashboard Features

🔽 Marketing Funnel Chart

🥧 Conversion Pie Chart

👔 Conversion Rate by Job

📅 Conversion Rate by Month

Dashboard image is saved automatically in:

output/marketing_dashboard.png
